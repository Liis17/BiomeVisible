## Назначение и границы

Корень репозитория является корнем датапака: игра читает `pack.mcmeta` и папку `data/`. Задача проекта — показывать текст на экране при входе игрока в новый для него биом. Эта логика пока не реализована.

## Стек

| Технология | Роль | Источник |
|------------|------|----------|
| Minecraft Java Edition, датапак | Среда исполнения | `pack.mcmeta` |
| JSON | Формат манифеста | `pack.mcmeta` |

## Текущая структура

```text
pack.mcmeta                      # манифест датапака
data/biomevisible/function/      # namespace biomevisible; пока пусто (.gitkeep)
```

Функций, достижений и других игровых файлов в репозитории нет.

## Компоненты

Компонентов с кодом пока нет. Заметки по доменам появятся вместе с реализацией.

## Ограничения и инварианты

- `min_format` и `max_format` в `pack.mcmeta` должны соответствовать формату датапаков целевой версии игры.
- Namespace датапака — `biomevisible`; его файлы лежат в `data/biomevisible/`.

## Решения и основания

- **Манифест с `min_format`/`max_format`, без `pack_format`.** Основание: с Minecraft 1.21.9 диапазон версий задаётся этими полями; страница Minecraft Wiki [Pack format](https://minecraft.wiki/w/Pack_format) приводит такой пример. Ограничение: `supported_formats` в новых версиях не используется.
- **Значение `121`.** Основание: таблица форматов датапаков на той же странице указывает `121.0` для версии 26.3. Страница предупреждает, что таблицы могут устареть, поэтому значение не проверено в игре.
- **Корень репозитория — корень датапака.** Основание: требование пользователя иметь минимальный набор файлов, который игра распознаёт как датапак.
