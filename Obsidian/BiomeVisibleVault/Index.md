# BiomeVisible — База знаний

Датапак для Minecraft Java Edition 26.3 показывает локализованный заголовок при первом обнаружении игроком каждого из 67 ванильных биомов.

## Архитектура

- [[Architecture|Архитектура]] — структура датапака, функции обнаружения, персональные маркеры, очередь и ограничения

## Проверка

- `tools/check_datapack.py` — статическая проверка JSON, ссылок, 67 биомов и переводных ключей по официальному клиентскому jar 26.3

Пути исходников в заметках отсчитываются от корня репозитория. Changelog и дневники задач не ведутся.
