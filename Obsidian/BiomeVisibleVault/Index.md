# BiomeVisible — База знаний

Датапак и ресурс-пак для Minecraft Java Edition 26.3 показывают локализованное крупное название при первом обнаружении игроком каждого из 67 ванильных биомов; за новое открытие начисляется 5 очков опыта.

## Архитектура

- [[Architecture|Архитектура]] — структура датапака и ресурс-пака, функции обнаружения, персональные маркеры, очередь, награда опытом и ограничения

## Проверка

- `tools/check_datapack.py` — статическая проверка JSON, ссылок, 67 биомов, переводов en/ru и шрифтов по официальным ресурсам Minecraft 26.3; для русской части передать `--ru-lang <ru_ru.json>`

Пути исходников в заметках отсчитываются от корня репозитория. Changelog и дневники задач не ведутся.
