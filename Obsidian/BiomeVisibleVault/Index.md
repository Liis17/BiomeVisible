# BiomeVisible — База знаний

Датапак и ресурс-пак для Minecraft Java Edition 26.3 показывают крупное название вверху окна (русское при ru_ru, иначе английское) при первом обнаружении игроком каждого из 67 ванильных биомов; за новое открытие начисляется 5 очков опыта.

## Архитектура

- [[Architecture|Архитектура]] — структура датапака и ресурс-пака, функции обнаружения, персональные маркеры, очередь, награда опытом и ограничения

## Проверка

- `tools/test_build_release.py` — проверка сборки ZIP, общих версий и списка коммитов в изолированном Git-репозитории без публикации

- `tools/check_datapack.py` — статическая проверка JSON, ссылок, 67 биомов, переводных ключей en/ru, bitmap-таблиц и геометрии шейдера по официальным ресурсам Minecraft 26.3; для русской части передать `--ru-lang <ru_ru.json>`

- `tools/build_title_assets.py` — генерация блоков из официальных en/ru названий и bitmap-шрифтов, максимум два слова названия в строке; `--check` сверяет готовые ресурсы (требуется Pillow).

Пути исходников в заметках отсчитываются от корня репозитория. Changelog и дневники задач не ведутся.
