# Architecture

## Назначение и границы

Датапак лежит в папке `datapack/`, и она является его корнем: игра читает `datapack/pack.mcmeta` и папку `datapack/data/`. Корень репозитория содержит служебные файлы проекта и заметки. Задача проекта — показывать текст на экране при входе игрока в новый для него биом. Эта логика пока не реализована.

## Текущая структура

```text
datapack/pack.mcmeta                      # манифест датапака
datapack/data/biomevisible/function/      # namespace biomevisible; пока пусто (.gitkeep)
```

Функций, достижений и других игровых файлов в репозитории нет.

## Компоненты

Компонентов с кодом пока нет. Заметки по доменам появятся вместе с реализацией.

## Ограничения и инварианты

- `min_format` и `max_format` в `datapack/pack.mcmeta` должны соответствовать формату датапаков целевой версии игры.
- Namespace датапака — `biomevisible`; его файлы лежат в `datapack/data/biomevisible/`.

## Решения и основания

- **Манифест с `min_format`/`max_format`, без `pack_format`.** Основание: с Minecraft 1.21.9 диапазон версий задаётся этими полями; страница Minecraft Wiki [Pack format](https://minecraft.wiki/w/Pack_format) приводит такой пример. Ограничение: `supported_formats` в новых версиях не используется.
- **Значение `121`.** Основание: таблица форматов датапаков на той же странице указывает `121.0` для версии 26.3. Страница предупреждает, что таблицы могут устареть, поэтому значение не проверено в игре.
- **Датапак в отдельной папке `datapack/`.** Основание: требование пользователя вынести файлы датапака из корня репозитория.
