# BiomeVisible — База знаний

Датапак Minecraft Java Edition, который показывает текст на экране, когда игрок входит в биом, новый для этого игрока. Сейчас в репозитории есть только каркас датапака; игровой логики пока нет.

Стек: JSON-манифест `pack.mcmeta` и файлы датапака в `data/`. Сборки и автотестов в проекте нет.
