# BiomeVisible

Датапак для Minecraft Java Edition 26.3 показывает впервые обнаруженный игроком биом крупным белым заголовком по центру экрана. Название переводит сам клиент Minecraft, поэтому язык сообщения совпадает с языком игры; ресурс-пак не нужен.

## Установка

Скопируйте папку `datapack/` в папку мира `datapacks/` и назовите её `biomevisible`. Файл `pack.mcmeta` должен оказаться непосредственно в `datapacks/biomevisible/`. Затем войдите в мир и выполните `/reload`.

## Поведение

- Отслеживаются все 67 ванильных биомов Minecraft 26.3 во всех измерениях, включая `the_void`. Сторонние биомы не поддерживаются.
- Проверка выполняется каждый серверный тик по позиции ног игрока. Первый обнаруженный биом тоже ставится в очередь.
- Уже поставленные в очередь биомы идут в порядке обнаружения. Между заголовками проходит 100 игровых тиков онлайн (5 секунд при 20 TPS); пока игрок офлайн, очередь и таймер стоят на месте.
- Заголовок использует время 20/60/20 тиков: 20 тиков появления, 60 показа и 20 исчезновения. BiomeVisible задаёт эти параметры, и они остаются активными на клиенте до следующего изменения времени заголовка.
- История и прогресс маркеров сохраняются для каждого игрока после смерти, переподключения, `/reload` и перезапуска мира. Прошлые посещения до установки не импортируются: первый биом после установки считается новым.
- Работает для игроков в любом игровом режиме. Датапак не добавляет звуки, подзаголовки, команды сброса, ресурс-пак или мод.

Заголовок Minecraft общий для разных источников. Другая команда или датапак, который отправляет игроку title в то же время, может заменить сообщение BiomeVisible.

## Ручная проверка в игре

Эти проверки нужно выполнить на клиенте после установки; они не заменяют проверку файлов ниже.

1. Выполните `/reload` и убедитесь, что BiomeVisible включён командой `/datapack list enabled`.
2. На свежем игроке войдите в биом и проверьте, что его локализованное название появляется по центру. Перезайдите в уже обнаруженный биом — повторного сообщения быть не должно.
3. Быстро посетите несколько новых биомов и проверьте порядок сообщений и интервал. Оставьте игрока офлайн, затем вернитесь: очередь должна продолжиться с сохранённым остатком таймера.
4. Повторите проверку после смерти, переподключения, `/reload` и перезапуска мира.
5. В мультиплеере обнаружьте разные биомы двумя игроками и проверьте, что история, очередь и интервалы не смешиваются.

## Статическая проверка

Скрипт использует только стандартную библиотеку Python и официальный клиентский jar 26.3. Скачайте jar во временную папку и передайте путь скрипту:

```sh
curl -L 'https://piston-data.mojang.com/v1/objects/e877b6a07acd633fb3bb475002175cec036e7b87/client.jar' -o /tmp/biomevisible-mc-26.3-client.jar
python3 tools/check_datapack.py /tmp/biomevisible-mc-26.3-client.jar
```

Проверка разбирает JSON, ссылки на функции и маркеры, сверяет все биомы и переводные ключи с jar и проверяет формат датапака 121.
